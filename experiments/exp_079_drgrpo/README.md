# FINAL RESULTS — Qwen3-4B-Base

**Polarity-Aware Confidence-based Token-shaping** is our method: a per-token
credit-assignment layer that composes with *any* GRPO-family algorithm. Per token it uses an
EMA-smoothed top-k log-prob confidence signal C (top-k=5, λ=0.7), splits tokens by terminal
outcome polarity (O+/O−) with flipped roles (reward branching/exploratory tokens on correct
rollouts, penalize over-confident tokens on wrong ones), and applies a position discount
(τ=1024). The FIXED, group-visible implementation computes the shaped advantage on the full
generation group (avoiding the B=1 degeneracy). Because Polarity-Aware Confidence-based Token-shaping reshapes advantages rather than
changing the objective, "X + Polarity-Aware Confidence-based Token-shaping" denotes Polarity-Aware Confidence-based Token-shaping layered on base algorithm X — the same Polarity-Aware Confidence-based Token-shaping
configuration on every base.

## Takeaways

1. **Polarity-Aware Confidence-based Token-shaping is additive across token-level RL algorithms.** On the learnable datasets it lifts
   GRPO, DAPO, and Dr.GRPO by large margins (L50 Δ up to +0.89), and every peak-table shows
   X + Polarity-Aware Confidence-based Token-shaping reaching the base algorithm's *final* peak in **~⅓–½ the steps** — a
   convergence-speed story as strong as the accuracy one.
2. **Dr.GRPO + Polarity-Aware Confidence-based Token-shaping is the top learnable-set configuration** (peaks +2.67 / +2.51 / +2.36),
   consistent with our length-bias analysis: removing Dr.GRPO's length/difficulty bias and
   adding Polarity-Aware Confidence-based Token-shaping's decisive-token credit compound.
3. **GSPO is the boundary case.** Its tight *sequence-level* importance clipping partly
   absorbs the per-token advantage structure: Polarity-Aware Confidence-based Token-shaping still accelerates early convergence
   (reaches GSPO's peak 4–7× faster on MATH-500/BigMath) but does not improve final accuracy.
   This delimits *how* Polarity-Aware Confidence-based Token-shaping works — through per-token credit — an honest scope statement,
   not a failure.
4. **Base algorithms alone under-perform plain GRPO here** (DAPO/GSPO/Dr.GRPO all ≤ GRPO at
   300 steps, ng=4) — Polarity-Aware Confidence-based Token-shaping is what makes them competitive/best.
5. **Hard set (Omni-MATH) unchanged within noise** for every method — the open problem, and
   the motivation for the exp_071–075 principled roadmap (gate / bounded signal / budget).
