# exp_083 — Llama-3.2-3B-Instruct (exp_050 harness): original vs FIXED gtpo_ema_flipped

Reproduces the exp_050 Big-Math setup (custom working_out/SOLUTION tags, graded
format_exact/approximate + answer_exact/numeric rewards, 500 steps, max_completion 2048,
Llama-3.2-3B-Instruct) for three methods, to isolate the effect of the exp_058 FIX:

- `grpo` — plain baseline
- `gtpo_ema_flipped` — the **ORIGINAL** exp_050 trainer (overrides `_compute_loss`; per
  memory `shaping_bypassed_by_unsloth` this path is bypassed / B=1-degenerated by unsloth's
  compiled GRPOTrainer, so it likely runs ≈ plain GRPO or degenerates)
- `gtpo_ema_flipped_fixed` — the **FIXED** group-visible trainer (shaped advantage computed
  on the full group in `_generate_and_score`)

Both shaped flavours use the **same** config (α₁=0.9, α₂=0.1, λ=0.9, top_k=20 — exp_050's),
so any difference is purely the FIX. Tag-mask active on the four custom tags. bigmath only
(the exp_050 dataset); same hyperparameters as exp_082.

## Run
```
bash run_setup.sh        # grpo, gtpo_ema_flipped (orig), gtpo_ema_flipped_fixed — bigmath
python plot_compare.py   # figures/exp083_emaflip_fix_vs_orig.png (4-panel like exp_050)
```
