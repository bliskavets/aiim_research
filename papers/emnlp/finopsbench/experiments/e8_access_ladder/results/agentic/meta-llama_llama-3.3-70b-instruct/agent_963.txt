To calculate the increase in annual payments from 2019 to 2024 and beyond, we need to retrieve the maturity amounts for these periods.

First, let's find the year IDs for 2019 and "2024 and thereafter".

```python
year_id_2019 = find_year_id("2019")
year_id_2024_and_beyond = find_year_id("2024 and thereafter")
```

Then, we'll get the maturity amounts for these years.

```python
maturity_2019 = get_maturity_amount_for_yearsegment(year_id_2019)
maturity_2024_and_beyond = get_maturity_amount_for_yearsegment(year_id_2024_and_beyond)
```

The increase in annual payments can be calculated as the difference between the maturity amounts for "2024 and thereafter" and 2019.

```python
increase = maturity_2024_and_beyond - maturity_2019
```

Finally, we can return the result.

```python
print(increase, "thousand")
```
