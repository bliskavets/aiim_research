# Сводка репликационно-диагностической кампании 17-20 июля 2026

Хронологический перечень всех экспериментов этой сессии (детали — записи 19-28 в
EXPERIMENTS_LOG.md; по-задачные артефакты — per_problem_repro/). Всё на Qwen3-8B-FP8,
1x H200, vLLM 0.11.0. Судья для мэтчинга: o3 (первые регрейды) -> gpt-4.1-mini
(согласие с o3 93.2%, выбран по шутауту на 207 парах).

## Термины
- **orig-движок** — исходный сетап TTA: raw /v1/completions + суффикс ` /nothink`
  (soft-switch НЕ срабатывает; модель отвечает как текстовый продолжатель).
- **fixed-движок** — канонический non-thinking: chat template + префилл пустого
  <think></think> (байт-в-байт официальный enable_thinking=False).
- **hard-50** — 50 задач MATH-500, seed-7 перетасовка (сабсет ноутбуков exp_10;
  сложнее среднего: baseline 82 semantic против 88+ на полных 500).

### max_tokens свип (orig-движок, hard-50): бюджет НЕ влияет
4096 даёт 1 обрезку из 50; та единственная задача (284) не решается и при
6144/8192/16384/24576. Гипотеза «92 из-за большего бюджета» закрыта.
Примечание: >4096 на сервере с контекстом 32768 требует fit-to-context усечения
кандидатов в reflection (иначе 400 overflow) — в оригинале, вероятно, был сервер
с контекстом 40960.

### Решающий full-500 (orig-движок, seed 42): 450/500 = 90.0 semantic
Парно против кампании (fixed, тот же сид): 90.0 vs 88.8, discordant 38-32,
McNemar p=0.55 — на полном сете преимущество orig-движка НЕ значимо.
Обрезок 31/500 (6.2%). ВЫВОД: честный диапазон MATH-500 = 88.3-90.0;
92.0 на полном сете не подтверждается (это число hard-сабсета).

- full-500 orig-движок, сиды 7 и 123: на ~270/500 идут 87.5-89.7% — согласуется

  reasoning», а не попытка заявить выигрыш.

## Практические уроки инфраструктуры (в протокол)
1. Проверять sha256 модельных блобов при аномалиях качества (порча не меняет mtime).
2. Клиентские таймауты >=1500 c при нескольких SAGE-джобах на одном сервере;
   таймауты-ошибки считать и вычищать (они маскируются под «обрезки»).
3. Никогда не pkill по паттерну, входящему в собственную команду (5 само-убийств
   за сессию); kill только по явным PID.
4. continue-from дублирует унаследованные записи в новый файл — при подсчётах
  дедуплицировать по index; после kill старые процессы могут воскрешать файлы.
5. gpt-4.1-mini как судья мэтчинга: 93.2% согласия с o3, ~в 100 раз дешевле.
